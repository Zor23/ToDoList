# Aplikasi To-Do List

Sebuah aplikasi web sederhana untuk mengelola daftar tugas (To-Do List). Aplikasi ini dibangun menggunakan HTML, CSS, dan JavaScript murni (Vanilla JS).

## Fitur

Aplikasi ini memiliki beberapa fitur utama:
1. **Tambah Tugas**: Pengguna dapat menambahkan tugas baru melalui kolom input. Penambahan tugas dapat dilakukan dengan menekan tombol "Tambah" atau dengan menekan tombol `Enter` pada keyboard.
2. **Tandai Selesai**: Terdapat checkbox pada setiap tugas. Jika dicentang, teks tugas akan dicoret (strikethrough) sebagai penanda bahwa tugas telah selesai.
3. **Edit Tugas**: Pengguna dapat mengubah teks tugas yang sudah ada dengan menekan tombol "Edit".
4. **Hapus Tugas**: Pengguna dapat menghapus tugas dari daftar dengan menekan tombol "Hapus".

## Struktur Folder dan File

Proyek ini terdiri dari 3 file utama:

- `index.html`: Berisi struktur dasar halaman web dan elemen antarmuka pengguna (UI) seperti input teks, tombol, dan daftar tugas.
- `style.css`: Berisi gaya (styling) untuk mempercantik tampilan antarmuka, membuat aplikasi terlihat responsif dan nyaman digunakan.
- `script.js`: Berisi logika JavaScript untuk menangani interaksi pengguna, seperti manipulasi elemen DOM untuk menambah, mengedit, menghapus, dan menandai status tugas.

## Cara Penggunaan

1. Pastikan semua file (`index.html`, `style.css`, dan `script.js`) berada dalam satu folder/direktori.
2. Buka file `index.html` menggunakan web browser pilihan Anda (Google Chrome, Mozilla Firefox, Microsoft Edge, dll).
3. Ketikkan tugas baru di kolom input.
4. Klik tombol **Tambah** atau tekan **Enter** untuk memasukkan tugas ke dalam daftar.
5. Gunakan **Checkbox** untuk menandai tugas yang sudah selesai.
6. Klik tombol **Edit** untuk mengubah teks tugas, atau klik **Hapus** untuk menghapusnya secara permanen dari daftar.

## Teknologi yang Digunakan

- HTML5
- CSS3
- JavaScript (ES6)
